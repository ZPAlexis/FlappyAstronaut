# Flappy Astronaut

**A demo Unity game to implement game development and C-sharp concepts. Inspired by the game Flappy Bird.**

My first Unity project (2023). The player guides an astronaut through a field of asteroids while managing a limited supply of oxygen, and the goal is to stay alive for as long as possible.

**[Read the case study](https://acoelho.dev/en/projects/flappy_astronaut)** · [Playable Windows build](https://github.com/ZPAlexis/FlappyAstronaut/releases/tag/v1.0.0)

> **Archived:** a finished learning prototype. It was one of the opportunities I took to turn a long-standing interest in game design into hands-on practice, enriching the foundation of the gamified products and experiences I build today.

Built with Unity 2021.3 and C#.
